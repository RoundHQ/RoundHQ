# AI Receptionist Telnyx Setup

RoundHQ AI Receptionist launches in **Voicemail-to-Lead** mode.

Live realtime AI conversations are not part of the production launch. They should remain hidden or disabled until the later realtime upgrade is reviewed separately.

## Required Environment Variables

Add these to local, staging, and production server environments:

```env
AI_RECEPTIONIST_SECRET_ENCRYPTION_KEY=
AI_RECEPTIONIST_PUBLIC_BASE_URL=
AI_RECEPTIONIST_INTAKE_TOKEN=
```

`AI_RECEPTIONIST_SECRET_ENCRYPTION_KEY` is required before saving Telnyx API keys or legacy Twilio auth tokens. Use a long random value, preferably a 32-byte base64 secret generated by your deployment secret manager.

`AI_RECEPTIONIST_PUBLIC_BASE_URL` must be the public HTTPS origin Telnyx can call, for example:

```env
AI_RECEPTIONIST_PUBLIC_BASE_URL=https://app.roundhq.co.uk
```

## Telnyx Account Setup

1. Create or sign in to a Telnyx account.
2. Buy or port the phone number that will receive AI Receptionist calls.
3. Create a Call Control application or connection for that number.
4. Create or choose a Messaging Profile for future SMS support.
5. Copy the Telnyx API key.
6. Copy the Telnyx webhook public key from the Telnyx portal.

## Webhook URLs

Configure Telnyx to send voice webhooks to:

```text
https://YOUR_PUBLIC_ROUNDHQ_DOMAIN/api/ai-receptionist/telnyx/incoming-call
https://YOUR_PUBLIC_ROUNDHQ_DOMAIN/api/ai-receptionist/telnyx/recording-complete
https://YOUR_PUBLIC_ROUNDHQ_DOMAIN/api/ai-receptionist/telnyx/call-status
```

The exact Telnyx event names may vary by Call Control configuration, but RoundHQ expects JSON webhook payloads containing:

- `data.id`
- `data.event_type`
- `data.payload.call_control_id`
- `data.payload.call_session_id`
- `data.payload.from`
- `data.payload.to`
- recording URL fields on recording completion
- transcript or transcription text when available

Webhook requests must include Telnyx signature headers:

- `telnyx-timestamp`
- `telnyx-signature-ed25519`

RoundHQ rejects invalid signatures, stale signatures, and unknown called numbers.

## RoundHQ Settings

In RoundHQ:

1. Open `Settings -> AI Receptionist`.
2. Set provider to `Telnyx`.
3. Add:
   - Telnyx phone number
   - Telnyx API key
   - Telnyx connection / app ID
   - Telnyx messaging profile ID
   - Telnyx public key
4. Save settings.
5. Enable AI Receptionist when the Telnyx connection is ready.

Secrets are encrypted before being stored. The frontend only receives masked/configured status.

## Customer Number Forwarding

For launch, customers should forward their existing business number to the configured Telnyx number, or publish the Telnyx number directly.

The inbound flow is:

```text
Incoming call
-> Telnyx webhook
-> RoundHQ resolves organisation from called number
-> Telnyx plays greeting/consent/prompt
-> Telnyx records voicemail
-> RoundHQ receives recording callback
-> RoundHQ creates a lead
-> RoundHQ stores transcript/activity/call log
```

There is no fallback to a default organisation. If the called number does not match one configured RoundHQ organisation, the webhook is rejected.

## SMS Foundation

RoundHQ can send internal test SMS messages through Telnyx from the AI Receptionist settings page.

Future SMS use cases include:

- quote follow-ups
- customer messages
- job reminders

Automatic quote messaging is not part of this launch.

## Recording Privacy

New Telnyx-created lead activity stores a recording id, not the raw provider recording URL.

Playback uses:

```text
GET /api/ai-receptionist/recordings/:id
```

This endpoint requires an authenticated RoundHQ user, checks workspace access, then fetches the provider recording server-side.

## Local Testing

For local webhook testing:

1. Run the app locally.
2. Expose it with a secure tunnel.
3. Set `AI_RECEPTIONIST_PUBLIC_BASE_URL` to the tunnel HTTPS origin.
4. Configure the Telnyx webhook URLs with that tunnel origin.
5. Save the Telnyx phone number and public key in RoundHQ settings.

Run the focused test suite:

```bash
npm run test:ai-receptionist-telnyx
```

## Staging Checklist

Before staging calls:

1. Apply `supabase/ai_receptionist_telnyx.sql`.
2. Set `AI_RECEPTIONIST_SECRET_ENCRYPTION_KEY`.
3. Set `AI_RECEPTIONIST_PUBLIC_BASE_URL`.
4. Save Telnyx settings for the staging organisation.
5. Place an inbound test call.
6. Confirm a lead appears in the existing Leads Inbox.
7. Confirm the lead activity shows summary, transcript status, duration, and recording playback.
8. Confirm an unknown Telnyx number is rejected.
9. Confirm invalid webhook signatures are rejected.

## Current Launch Limitation

RoundHQ AI Receptionist is **voicemail-to-lead only** for launch.

Do not market or expose live realtime AI conversations until the realtime media bridge, latency, monitoring, safety controls, and production support model have been reviewed separately.
